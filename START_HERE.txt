MOYO+ 웹사이트 - 빠른 실행

1) 압축을 푼 폴더에서 index.html을 Chrome 또는 Edge로 여세요.
2) 검색, 카테고리/요금/모바일/검증 필터, 상세보기, 외부 사이트 이동, 브라우저 즐겨찾기를 테스트할 수 있습니다.
3) 실제 공동 즐겨찾기, 실시간 접속자, 관리자 로그인/등록/수정/삭제/이미지 업로드는 Supabase 설정이 필요합니다.
4) Supabase SQL Editor에서 supabase-schema.sql을 실행하고, 관리자 Auth 계정과 moyo_admins 등록을 마친 뒤 supabase-config.js에 Project URL과 Publishable key를 입력하세요.
5) README.md에 Vercel 배포 순서가 있습니다.

중요: 현재 파일은 로컬 미리보기/배포 가능한 정적 웹사이트입니다. Supabase 연결값이 비어 있으므로 공용 DB와 관리자 인증은 아직 활성화되지 않았습니다. service_role/secret 키를 브라우저 파일에 넣지 마세요.


SUPABASE 연결 정보는 supabase-config.js에 반영되어 있습니다.
supabase-schema.sql 전체를 Supabase SQL Editor에서 실행한 뒤 관리자 계정을 등록하세요.
